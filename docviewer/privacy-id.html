Informasi yang diproses

Aplikasi ini tidak memiliki pendaftaran akun, iklan, atau server analitik milik sendiri. File dokumen dan teks yang dikenali diproses di perangkat Anda. Google ML Kit dan layanan Google Play, yang digunakan untuk mencari dalam PDF hasil pemindaian, dapat memproses informasi teknis untuk diagnostik dan statistik penggunaan.

Informasi ini dapat mencakup produsen, model, dan sistem operasi perangkat; paket dan versi aplikasi; pengenal perangkat atau instalasi; waktu pemrosesan pengenalan; format dan resolusi gambar masukan serta ukuran masukan dan keluaran; versi SDK; peristiwa pengunduhan model dan pengenalan; serta kode kesalahan. Menurut Google, transmisi dienkripsi menggunakan HTTPS, dan gambar dokumen serta teks yang dikenali itu sendiri tidak dikirim ke server Google.

Untuk detail, lihat pengungkapan data Google ML Kit untuk Android dan Kebijakan Privasi Google melalui tautan di bawah.

Kebijakan Privasi Google

File dokumen

Dokumen yang Anda buka dibaca dan ditampilkan di perangkat Anda. Aplikasi tidak mengunggahnya langsung ke server. Jika Anda memilih “Kirim ke Gemini” atau “Bagikan dokumen”, aplikasi memberikan akses baca ke dokumen asli kepada aplikasi yang dipilih. Aplikasi penerima dapat mengunggahnya ke server sesuai kebijakan layanan tersebut.

Informasi yang disimpan di perangkat Anda

Pencarian dan sorotan dalam PDF hasil pindai menggunakan Google ML Kit untuk mengenali teks bahasa Korea, Inggris, Hindi, Mandarin, Jepang, Spanyol, Portugis, Indonesia, Prancis, dan Jerman di perangkat. Dari lima model aksara Latin, Korea, Mandarin, Jepang, dan Dewanagari, hanya model yang diperlukan diunduh melalui layanan Google Play saat pertama digunakan. Unduhan pertama setiap model mungkin memerlukan internet; pengenalan selanjutnya tetap dilakukan di perangkat. Dokumen dan teks yang dikenali tidak dikirim ke server. Gambar untuk pencarian dilepaskan dari memori setelah pemrosesan.

Daftar file terbaru (nama dan lokasi file) disimpan dalam penyimpanan privat aplikasi di perangkat Anda agar dokumen dapat dibuka kembali. Hingga 30 entri disimpan; membuka file baru menghapus entri terlama. Menghapus data aplikasi melalui pengaturan perangkat atau mencopot pemasangan aplikasi akan menghapus daftar ini. Aplikasi tidak menghapus dokumen asli Anda; Anda dapat menghapusnya melalui pengelola file. Pencadangan otomatis data aplikasi dinonaktifkan.

Berbagi dengan pihak ketiga

Dokumen asli hanya diteruskan ke aplikasi yang dipilih saat Anda menggunakan fitur berbagi. Selain itu, file dokumen dan teks yang dikenali tidak diberikan kepada pihak ketiga. Informasi teknis yang diproses oleh layanan Google untuk OCR dan pengiriman model dijelaskan dalam bagian informasi di atas dan Kebijakan Privasi Google.
